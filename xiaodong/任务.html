任务模块逻辑说明

切换左侧模块时，本面板自动定位并高亮对应规则；鼠标悬停界面元素可联动高亮逻辑。

1五大任务状态定义（含权限）

状态定义允许操作
草稿未发布，仅保存编辑 / 发布 / 删除
未执行已发布，执行人未提交执行 / 转发 / 撤回 / 调整执行人
执行中部分提交，未全部完成禁止撤回；未提交人可提交/转交
已完成执行人提交后闭环，数据锁定归档仅查看 / 复制，不可改
已撤回发起人主动撤回详情 / 编辑 / 重新发布

关键：所有任务类型均由执行人提交后直接闭环，不存在审批环节。

2两类任务流转规则总览

  • ① 普通业务表单任务：表单类型=「普通业务表单」。执行人提交表单即闭环为「已完成」。
  • ② 无表单任务：表单类型=「无」。执行人填写完成情况并提交即闭环为「已完成」。
  • ③ BPM 流程表单任务：表单类型=「BPM流程表单」。执行人提交即闭环为「已完成」；BPM 流程自身状态另行驱动。

3任务流转：执行人提交 → 已完成（无审批、无动态发布环节）

未执行— 执行人提交 —▶已完成 单人：提交即闭环（无审批）。
未执行— 任一提交 —▶执行中— 全员提交 —▶已完成 多人：部分提交保持「执行中」，禁止撤回；末人提交后闭环。

4BPM 流程表单任务流转

未执行—发起BPM—▶执行中—提交—▶已完成 执行人提交即闭环为「已完成」（无动态发布环节）。

6角色权限说明

  • 超级管理员：全部权限——创建/编辑模板、启停模板、发布任务、查看所有台账、调整人员、结束任务。
  • 任务发布者：发布任务、保存草稿、管理自己发布的任务；无模板、台账权限。
  • 普通执行者：仅查看个人任务、执行、转发；无模板、发布、台账权限。

7五大模块交互逻辑

① 任务模板

  • 「创建任务模板」进入编辑页（基本信息 + 全局规则两个 Tab）。
  • 保存校验：模板名称非空，通过后回填列表。
  • 停用模板不可发布；启用状态模板不可直接删除（需先停用）。
  • 模板编辑不影响已发布任务，仅对后续引用生效。

② 发布任务

  • 前置：先选「启用」模板，再进入填写页（基本信息配置 / 全局规则配置 两个 Tab）。
  • 表单结构由模板固定，仅可填内容，不可改字段。
  • 全局规则默认读模板，可二次覆盖。
  • 保存草稿→进草稿列表；正式发布→同时写入「我发起的 / 待我执行 / 我参与的」。

③ 我的任务（7 标签）

  • 草稿任务：编辑（预填发布页）/ 直接发布 / 删除。
  • 我发起的：详情 / 撤回（仅未执行）/ 复制。
  • 待我执行：执行（无表单填情况 / 有表单填表单）/ 转发。
  • 已执行：查看已提交任务的详情。
  • 我撤回的：详情 / 编辑重发 / 直接重发。
  • 其他（已转发 / 我参与的）：仅查看详情。

④ 台账（仅管理员）

  • 总台账：查看 / 调整执行人 / 结束 / 复制 / 导出。
  • 人员明细：查看 / 导出。
  • 调整执行人：未执行可调整；执行中仅调未提交人员。
  • 结束任务：未完成的任务可强制结束（二次确认）。

8超期标记机制

  • 判定：当前时间 ＞ 计划结束时间 且 状态 ≠ 已完成 → 自动追加「已超期」。
  • 操作：超期仅用于标红、提醒、台账统计，不限制任何提交 / 重提。
  • 留存：超期后完成的任务永久保留超期记录，用于绩效考核与追溯。

8全局规则配置说明

  • 执行控制：开启后仅计划开始时间后才可执行；关闭则收到即可执行。
  • 周期重复：不重复 / 按天 / 按周 / 按月 / 按年 + 发布时间 + 截止日期。
  • 消息提醒：自动推送、开始前/结束前时长、超期督办、接收人多选。
  • 模板预设为默认值，发布时可二次覆盖，灵活适配单次差异。

9任务 ID 生成规则

固定格式：T + 时间戳后 8 位 + 3 位随机数字，全局唯一。示例：T26874512345（模板 ID 为 TPL001 等）。

10任务状态流转全景图

草稿 ─发布─▶ 未执行
未执行 ─任一提交─▶ 执行中 ─全员提交─▶ 已完成（闭环）
未执行 ─撤回─▶ 已撤回

说明：所有任务执行人提交后直接闭环为「已完成」，无审批、无动态发布环节。
