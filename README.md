# 澄明工作台

基于 React 和 Vite 构建的静态工作台演示应用。

## 本地运行

```bash
npm ci
npm run dev
```

## 生产构建

```bash
npm run build
```

构建完成后，静态站点文件位于 `dist/`。

## 帽子云发布

本项目可直接作为静态网站发布，无需配置服务端或环境变量。

1. 将本项目推送至 GitHub 仓库。
2. 在 [帽子云控制台](https://dash.maoziyun.com/login) 创建应用并授权 GitHub。
3. 选择该仓库及待发布分支。
4. 在“构建设置”中填写：

| 配置项 | 值 |
| --- | --- |
| 根目录 | `.` |
| 构建命令 | `npm run build` |
| 输出目录 | `dist` |
| Node.js | `22` |

5. 保存后发起部署；选择自动部署时，后续推送到该分支会自动更新站点。

发布后若页面未立即更新，帽子云默认可能有约 20 分钟的浏览器缓存；可使用无痕窗口验证最新版本。
